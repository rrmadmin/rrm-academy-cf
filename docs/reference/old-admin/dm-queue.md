# Old Admin: DM Queue

Source: `src/pages/admin/dm-queue.astro` + `functions/api/admin/dm-queue.js` (list) + `functions/api/admin/dm-queue/[id].js` (action)

## Purpose

Human approval queue for LLM-drafted Instagram DM and comment replies generated by the rrm-dm-agent worker; lets an admin review, edit, approve-and-send, or reject each pending draft before it goes out.

## API endpoints the page calls

- `GET /api/admin/dm-queue` -- list pending drafts + counts.
- `POST /api/admin/dm-queue/:id` -- body `{ action: 'approve', finalText }` or `{ action: 'reject' }`.

## Data model

D1 `rrm-auth`, `dm_` prefixed tables (read by list endpoint, dm-agent worker is the writer):
- `dm_draft` -- id, thread_igsid, source (`dm`|`comment`), source_ref, tier, intent, draft_text, final_text, status (`pending`/`approved`/`rejected`), window_expires_at, created_at, decided_at, decided_by.
- `dm_thread` -- igsid, needs_human flag, suppressed flag (opted-out threads), last_inbound_at.
- `dm_message` -- mid, thread_igsid, direction (`in`/`out`/`echo`), text, created_at, is_ack. Most recent 3 per thread are shown.
- `dm_comment` -- comment_id, from_username, text (only joined when `source = 'comment'`).

List response: `{ drafts: [...], counts: { pending, needsHuman, suppressed } }`. Pending drafts capped at 100 (`DRAFT_LIMIT`), ordered oldest first. Suppressed threads are excluded from the visible list but counted separately.

**Approve does not write `dm_draft` directly.** It calls the rrm-dm-agent Worker's bearer-gated `POST /internal/send` (env `DM_AGENT_URL` + `DM_AGENT_SEND_SECRET`, matches worker's `INTERNAL_SEND_SECRET`), which owns the claim CAS, the IG token, and send logging. If those env vars are unset, approve fails closed with 503 `worker_not_configured`. Reject is a direct D1 CAS `UPDATE dm_draft SET status='rejected' ... WHERE status='pending'` (409 `already_actioned` if another admin beat it).

## Actions available in the UI

- **Refresh** button -- reloads the list.
- Per-card **editable textarea** (pre-filled with `draftText`), with a live byte counter (max 1000 bytes, UTF-8) and a live countdown to `windowExpiresAt` (Instagram's 24h messaging window; urgent styling under 4h, disabled past expiry).
- **Approve & Send** -- confirms via `window.confirm` showing the exact text + byte count, then POSTs `{ action: 'approve', finalText }`. Disabled if over byte limit or window expired.
- **Reject** -- confirms, then POSTs `{ action: 'reject' }`. Draft is not sent.
- Cards auto-remove from the list on success; a toast confirms; a banner surfaces `worker_not_configured` or `sends_disabled` (kill switch) states.
- Auto-refreshes countdown/byte state every 30s (does not re-fetch the list, only recomputes displayed state).

## Auth level required

Superadmin session auth (`requireSuperAdmin`) on both endpoints. Same best-effort session middleware as the other admin pages.

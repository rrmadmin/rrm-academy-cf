# Library Taxonomy (D1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. The controller uses the `jev-controller` skill helpers (jev-triage, jev-next, jev-watch, preflight-pairs) between tasks.

**Goal:** One closed three-level topic taxonomy in a single file, every published paper classified into it by Jev with confidence, low-confidence papers in a Gianna-worked review queue, the topics pages rebuilt from slug paths with counts.

**Architecture:** The taxonomy lives in `src/data/library-taxonomy.json` (rrm-academy-cf) and generates the existing `library-topics.ts` exports so the pages keep their shape. The library worker's `/classify-result` route gains an optional `topics` field (slug paths), joins it to the idempotency comparison, and stays the ONLY writer. A session-run script classifies papers through Jev's hierarchical Choice (domain, then topic, then subtopic) and posts through that route; a 200-paper Gianna sample gates the full run; a D1 export precedes any write.

**Tech Stack:** Node 22+ ESM, `node --test` (rrm-academy-cf), vitest (rrm-library-worker), Cloudflare D1 `rrm-library`, wrangler, Jev via `~/iCode/skills/jev-controller/lib/jev.mjs`.

**Spec:** `docs/superpowers/specs/2026-09-18-search-and-taxonomy-revamp-design.md` sections 3, 6, 8, 9 (rulings 1, 3, 5). D2 and D3 get their own plans after this one is measured.

## Global Constraints

- **Two repos, fixed landing order.** Tasks 1 and 2 land in `rrm-library-worker` through its ritual (worktree off `origin/main`, branch `claude/<scope>`, PR, `gh pr merge --merge`, `npm run deploy:safe`, `harness/smoke.mjs` green) and are LIVE before Task 6 posts anything. Everything else lands in `rrm-academy-cf` (direct push to `main` deploys).
- **No clinical prose in this plan or in any file the main thread reads.** Topic and subtopic NAMES are authored by Gianna and signed by Naomi (spec section 3). Every example below uses placeholder slugs (`domain-a`, `topic-a1`). The clustering task and the sample-labeling task run in subagents; the main thread sees counts and slugs only.
- **`/classify-result` is the only writer of `topics`.** No script runs `UPDATE articles` directly. Task 10 finds and retires anything that does.
- **`--apply` is never the default.** Every script that can write prints its plan and exits 0 without `--apply`; with `--apply` it refuses unless the pre-run export in Task 7 exists and is under 24 h old.
- **Jev threshold 0.5.** Below it at any level the paper goes to the review queue, never into the tree.
- **Key posture.** `TYPESAFE_API_KEY` from the environment or `op read op://Automation/TypeSafe API Key/credential` inside `jev.mjs`; never printed, never logged. Worker admin token: `SMOKE_ADMIN_TOKEN` (1P Automation), same rule.
- **American English in every string that could reach a page.** No em dashes anywhere.
- **Domain enum on the worker is the 23 title-case values in `check_domain`** (`rrm-cli/schema/d1-library.sql`). The taxonomy's `legacyDomain` field maps each new domain to one of them; the script never invents a `domain` value.
- Path regex for a stored topic path: `^[a-z0-9-]+(\/[a-z0-9-]+){0,2}$`. One to three paths per paper, primary first.

```js
export const TOPIC_PATH_RE = /^[a-z0-9-]+(\/[a-z0-9-]+){0,2}$/;

/** Returns null when valid, else an error string. `undefined` means "not supplied" and is valid. */
export function validateTopics(topics) {
  if (topics === undefined) return null;
  if (!Array.isArray(topics) || topics.length < 1 || topics.length > 3) return 'topics must be an array of 1 to 3 paths';
  const seen = new Set();
  for (const p of topics) {
    if (typeof p !== 'string' || !TOPIC_PATH_RE.test(p)) return `topics path is not a slug path: ${String(p).slice(0, 80)}`;
    if (seen.has(p)) return `topics has a duplicate path: ${p}`;
    seen.add(p);
  }
  return null;
}
```

```js
// src/data/library-taxonomy.schema.mjs
export const SLUG_RE = /^[a-z0-9]+(-[a-z0-9]+)*$/;
export const LEGACY_DOMAINS = [
  'Andrology/Male Factor', 'Body Literacy/Education', 'Bone Health', 'Bone Health/Adolescent Health',
  'Bone Health/Reproductive Endocrinology', 'Contraception/Comparison', 'Economics', 'Education',
  'Endometriosis', 'Fertility Awareness', 'General OB/GYN', 'Infertility', 'Menstrual Cycle',
  'NaProTECHNOLOGY', 'Other', 'PCOS', 'Perimenopause/Menopause', 'Postpartum', 'Pregnancy',
  'Reproductive Endocrinology', 'Research Methodology', 'Surgery', "Women's Health",
];

function checkNode(node, path, errors, seen) {
  if (typeof node.slug !== 'string' || !SLUG_RE.test(node.slug)) errors.push(`${path}: slug must match ${SLUG_RE}`);
  if (typeof node.label !== 'string' || !node.label.trim()) errors.push(`${path}: label required`);
  if (!Array.isArray(node.aliases)) errors.push(`${path}: aliases must be an array`);
  for (const s of ['label', 'descriptor']) if (typeof node[s] === 'string' && node[s].includes('\u2014')) errors.push(`${path}: em dash in ${s}`);
  const full = path ? `${path}/${node.slug}` : node.slug;
  if (seen.has(full)) errors.push(`duplicate path ${full}`);
  seen.add(full);
  return full;
}

export function validateTaxonomy(tree) {
  const errors = [];
  if (!tree || tree.version !== 1 || !Array.isArray(tree.domains)) return ['tree must have version 1 and a domains array'];
  const seen = new Set();
  for (const d of tree.domains) {
    const dp = checkNode(d, '', errors, seen);
    if (typeof d.descriptor !== 'string' || !d.descriptor.trim()) errors.push(`${dp}: descriptor required`);
    if (typeof d.browsable !== 'boolean') errors.push(`${dp}: browsable must be boolean`);
    if (!LEGACY_DOMAINS.includes(d.legacyDomain)) errors.push(`${dp}: legacyDomain must be one of the 23 check_domain values`);
    if (!Array.isArray(d.topics)) { errors.push(`${dp}: topics must be an array`); continue; }
    for (const t of d.topics) {
      const tp = checkNode(t, dp, errors, seen);
      if (!Array.isArray(t.subtopics)) { errors.push(`${tp}: subtopics must be an array`); continue; }
      for (const s of t.subtopics) checkNode(s, tp, errors, seen);
    }
  }
  return errors;
}

export function flattenPaths(tree) {
  const out = [];
  for (const d of tree.domains) {
    out.push(d.slug);
    for (const t of d.topics ?? []) { out.push(`${d.slug}/${t.slug}`); for (const s of t.subtopics ?? []) out.push(`${d.slug}/${t.slug}/${s.slug}`); }
  }
  return out;
}

export function legacyDomainFor(domainSlug, tree) {
  const d = tree.domains.find(x => x.slug === domainSlug);
  if (!d) throw new Error(`unknown domain slug ${domainSlug}`);
  return d.legacyDomain;
}

export function browsableDomains(tree) { return tree.domains.filter(d => d.browsable); }

export function labelForPath(path, tree) {
  const [a, b, c] = path.split('/');
  const d = tree.domains.find(x => x.slug === a); if (!d) return null;
  if (!b) return d.label;
  const t = d.topics.find(x => x.slug === b); if (!t) return null;
  if (!c) return t.label;
  const s = t.subtopics.find(x => x.slug === c); return s ? s.label : null;
}
```

```js
#!/usr/bin/env node
// Dumps every distinct existing topics path string with its count, plus the domain histogram.
// Read-only. Output feeds the vocabulary subagent; the main thread reads only the totals line.
import { execFileSync } from 'node:child_process';
import { writeFileSync, mkdirSync } from 'node:fs';
const sql = `SELECT domain, topics FROM articles WHERE status='published'`;
const raw = execFileSync('npx', ['wrangler', 'd1', 'execute', 'rrm-library', '--remote', '--json', '--command', sql], { encoding: 'utf8', maxBuffer: 1 << 28 });
const rows = JSON.parse(raw)[0].results;
const paths = new Map(); const domains = new Map(); let empty = 0;
for (const r of rows) {
  domains.set(r.domain, (domains.get(r.domain) ?? 0) + 1);
  let arr = []; try { arr = JSON.parse(r.topics ?? '[]'); } catch { arr = []; }
  if (!Array.isArray(arr) || arr.length === 0) { empty++; continue; }
  for (const p of arr) paths.set(p, (paths.get(p) ?? 0) + 1);
}
mkdirSync('.run/taxonomy', { recursive: true });
writeFileSync('.run/taxonomy/existing-paths.json', JSON.stringify({ total: rows.length, empty, domains: [...domains], paths: [...paths].sort((a, b) => b[1] - a[1]) }, null, 2));
console.log(`published=${rows.length} empty_topics=${empty} distinct_paths=${paths.size} distinct_domains=${domains.size}`);
```

```js
#!/usr/bin/env node
// scripts/taxonomy/classify.mjs
// Jev hierarchical Choice: domain -> topic -> subtopic, then one secondary path. Writes only through /classify-result.
import { readFileSync, writeFileSync, appendFileSync, mkdirSync, existsSync, statSync } from 'node:fs';
import { execFileSync } from 'node:child_process';
import { ask as jevAsk, choice } from `${process.env.HOME}/iCode/skills/jev-controller/lib/jev.mjs`;
import { validateTaxonomy, legacyDomainFor } from '../../src/data/library-taxonomy.schema.mjs';

export const THRESHOLD = 0.5;
export const MODEL_TAG = 'jev-latest-taxonomy-v1';
const WORKER = 'https://rrm-library-worker.administrator-cloudflare.workers.dev';

function nodeChildren(tree, chosen) {
  if (chosen.length === 0) return tree.domains;
  const d = tree.domains.find(x => x.slug === chosen[0]); if (!d) return [];
  if (chosen.length === 1) return d.topics ?? [];
  const t = d.topics.find(x => x.slug === chosen[1]); return t ? (t.subtopics ?? []) : [];
}

export function buildQuestions(stage, tree, chosen) {
  const kids = nodeChildren(tree, chosen);
  const criteria = Object.fromEntries(kids.map(k => [k.slug, `${k.label}${k.descriptor ? ': ' + k.descriptor : ''}${k.aliases?.length ? ' (also: ' + k.aliases.join(', ') + ')' : ''}`]));
  const level = { domain: 'top-level domain', topic: 'topic within the chosen domain', subtopic: 'subtopic within the chosen topic' }[stage];
  return { [stage]: { type: 'choice', instructions: `Which ${level} does the paper in \`paper\` (title, abstract, journal, year) belong to? Pick the single best fit.`, criteria } };
}

export function buildSecondaryQuestion(tree, primaryDomain) {
  const others = tree.domains.filter(d => d.slug !== primaryDomain);
  const criteria = { none: 'The paper belongs to no second domain.', ...Object.fromEntries(others.map(k => [k.slug, `${k.label}: ${k.descriptor}`])) };
  return { secondary: { type: 'choice', instructions: 'Besides its primary domain, does the paper in `paper` substantially belong to a second domain? Choose none unless a reader browsing that domain would expect to find it.', criteria } };
}

export async function classifyOne({ paper, tree, askImpl = jevAsk, threshold = THRESHOLD }) {
  const state = { paper: { title: paper.title ?? '', abstract: (paper.abstract ?? '').slice(0, 1500), journal: paper.journal ?? '', year: paper.year ?? null } };
  const chosen = []; const confidence = {};
  for (const stage of ['domain', 'topic', 'subtopic']) {
    if (nodeChildren(tree, chosen).length === 0) break;
    const res = await askImpl(state, buildQuestions(stage, tree, chosen));
    const c = choice(res.answers, stage);
    if (!c) return { paths: null, confidence, queue: true, reason: `${stage}: no answer` };
    confidence[stage] = c.confidence;
    if (c.confidence < threshold) {
      if (stage === 'domain') return { paths: null, confidence, queue: true, reason: `domain confidence ${c.confidence.toFixed(2)} below ${threshold}` };
      break; // stop at the last confident level
    }
    chosen.push(c.choice);
  }
  const primary = chosen.join('/');
  const paths = [primary];
  const sec = await askImpl(state, buildSecondaryQuestion(tree, chosen[0]));
  const s = choice(sec.answers, 'secondary');
  confidence.secondary = s?.confidence ?? null;
  if (s && s.choice !== 'none' && s.confidence >= threshold) paths.push(s.choice);
  return { paths, confidence, queue: false, reason: null };
}

export function buildBody(paper, paths, tree) {
  let traditions = []; try { traditions = JSON.parse(paper.traditions ?? '[]'); } catch { traditions = []; }
  return {
    article_id: paper.id, domain: legacyDomainFor(paths[0].split('/')[0], tree), rrm_relevance: Number(paper.rrm_relevance),
    sentiment: paper.sentiment, traditions, evidence_weight: paper.evidence_weight, ai_reasoning: paper.ai_reasoning ?? '',
    classification_model: MODEL_TAG, topics: paths,
  };
}

async function fetchPapers(ids, limit) {
  const where = ids ? `AND id IN (${ids.map(i => `'${i.replace(/'/g, "''")}'`).join(',')})` : '';
  const sql = `SELECT id, title, abstract, journal, year, domain, rrm_relevance, sentiment, traditions, evidence_weight, ai_reasoning, topics FROM articles WHERE status='published' ${where} ORDER BY id ${limit ? 'LIMIT ' + Number(limit) : ''}`;
  const raw = execFileSync('npx', ['wrangler', 'd1', 'execute', 'rrm-library', '--remote', '--json', '--command', sql], { encoding: 'utf8', maxBuffer: 1 << 29 });
  return JSON.parse(raw)[0].results;
}

async function postClassification(body, token, fetchImpl = fetch) {
  const r = await fetchImpl(`${WORKER}/classify-result`, { method: 'POST', headers: { authorization: `Bearer ${token}`, 'content-type': 'application/json' }, body: JSON.stringify(body) });
  return { status: r.status, json: await r.json().catch(() => ({})) };
}

if (process.argv[1] && import.meta.url.endsWith(process.argv[1].split('/').pop())) {
  const a = process.argv.slice(2);
  const flag = (n) => { const i = a.indexOf(n); return i >= 0 ? a[i + 1] : undefined; };
  const apply = a.includes('--apply');
  const tree = JSON.parse(readFileSync('src/data/library-taxonomy.json', 'utf8'));
  const errs = validateTaxonomy(tree); if (errs.length) { console.error(errs.join('\n')); process.exit(2); }
  if (apply && !tree.signedBy) { console.error('refusing --apply: taxonomy is not signed (signedBy is null)'); process.exit(2); }
  if (apply) {
    const marker = '.run/taxonomy/backup.json';
    if (!existsSync(marker) || Date.now() - statSync(marker).mtimeMs > 24 * 3600 * 1000) { console.error('refusing --apply: run scripts/taxonomy/export-backup.mjs first (marker missing or older than 24h)'); process.exit(2); }
  }
  const ids = flag('--sample') ? readFileSync(flag('--sample'), 'utf8').split('\n').map(s => s.trim()).filter(Boolean) : null;
  const papers = await fetchPapers(ids, flag('--limit'));
  mkdirSync('.run/taxonomy', { recursive: true });
  const token = apply ? process.env.SMOKE_ADMIN_TOKEN : null;
  if (apply && !token) { console.error('refusing --apply: SMOKE_ADMIN_TOKEN not in environment'); process.exit(2); }
  let queued = 0, written = 0, idem = 0, failed = 0;
  const CONCURRENCY = 8; let i = 0;
  async function worker() {
    while (i < papers.length) {
      const p = papers[i++];
      const r = await classifyOne({ paper: p, tree });
      appendFileSync('.run/taxonomy/decisions.jsonl', JSON.stringify({ id: p.id, ...r, at: new Date().toISOString() }) + '\n');
      if (r.queue) { queued++; appendFileSync('.run/taxonomy/review-queue.jsonl', JSON.stringify({ id: p.id, reason: r.reason, confidence: r.confidence }) + '\n'); continue; }
      if (!apply) continue;
      const res = await postClassification(buildBody(p, r.paths, tree), token);
      if (res.status === 200 && res.json.idempotent) idem++; else if (res.status === 200) written++; else { failed++; appendFileSync('.run/taxonomy/failures.jsonl', JSON.stringify({ id: p.id, status: res.status, body: res.json }) + '\n'); }
    }
  }
  await Promise.all(Array.from({ length: CONCURRENCY }, worker));
  console.log(`papers=${papers.length} queued=${queued} ${apply ? `written=${written} idempotent=${idem} failed=${failed}` : 'dry-run (no writes)'}`);
}
```

```js
#!/usr/bin/env node
// scripts/taxonomy/export-backup.mjs: full articles table export before any taxonomy write. Refuses to overwrite today's file.
import { execFileSync } from 'node:child_process';
import { existsSync, mkdirSync, writeFileSync, statSync } from 'node:fs';

export function planBackup(now = new Date()) {
  const date = now.toISOString().slice(0, 10);
  const localPath = `.run/taxonomy/backup-${date}.sql`;
  return { date, localPath, gzPath: `${localPath}.gz`, r2Key: `backups/taxonomy/${date}.sql.gz`,
    exportArgs: ['wrangler', 'd1', 'export', 'rrm-library', '--remote', '--table', 'articles', '--output', localPath] };
}

if (process.argv[1] && import.meta.url.endsWith(process.argv[1].split('/').pop())) {
  const p = planBackup();
  mkdirSync('.run/taxonomy', { recursive: true });
  if (existsSync(p.gzPath)) { console.error(`refusing: ${p.gzPath} already exists`); process.exit(2); }
  execFileSync('npx', p.exportArgs, { stdio: 'inherit' });
  const bytes = statSync(p.localPath).size;
  if (bytes < 1_000_000) { console.error(`refusing: export is only ${bytes} bytes; expected a multi-MB articles table`); process.exit(2); }
  execFileSync('gzip', ['-f', p.localPath]);
  execFileSync('npx', ['wrangler', 'r2', 'object', 'put', `rrm-assets/${p.r2Key}`, '--file', p.gzPath, '--remote'], { stdio: 'inherit' });
  writeFileSync('.run/taxonomy/backup.json', JSON.stringify({ ...p, bytes, at: new Date().toISOString() }, null, 2));
  console.log(`backup ok: ${p.gzPath} -> r2://rrm-assets/${p.r2Key} (${bytes} bytes uncompressed)`);
}
```

```js
#!/usr/bin/env node
// scripts/gates/check-taxonomy.mjs: G2 every stored path resolves; G4 every browsable domain sits in [20, 800] or carries sizeRulingBy.
import { readFileSync } from 'node:fs';
import { flattenPaths, browsableDomains } from '../../src/data/library-taxonomy.schema.mjs';

export const BAND = { min: 20, max: 800 };

export function bucketBySlug(articles) {
  const m = new Map();
  for (const a of articles) for (const p of (Array.isArray(a.topics) ? a.topics : [])) { if (typeof p !== 'string') continue; const s = p.split('/')[0]; if (!m.has(s)) m.set(s, new Set()); m.get(s).add(a.id); }
  return m;
}

export function checkTaxonomy(articles, tree) {
  const legal = new Set(flattenPaths(tree));
  const unresolved = new Set();
  for (const a of articles) for (const p of (Array.isArray(a.topics) ? a.topics : [])) if (typeof p !== 'string' || !legal.has(p)) unresolved.add(String(p));
  const buckets = bucketBySlug(articles.filter(a => !unresolved.size || (a.topics ?? []).every(p => legal.has(p))));
  const bands = browsableDomains(tree).map(d => { const count = buckets.get(d.slug)?.size ?? 0; const inBand = count >= BAND.min && count <= BAND.max; return { slug: d.slug, count, ok: inBand || Boolean(d.sizeRulingBy), ruling: d.sizeRulingBy ?? null }; });
  return { unresolved: [...unresolved], bands, ok: unresolved.size === 0 && bands.every(b => b.ok) };
}

if (process.argv[1] && import.meta.url.endsWith(process.argv[1].split('/').pop())) {
  const tree = JSON.parse(readFileSync('src/data/library-taxonomy.json', 'utf8'));
  const articles = JSON.parse(readFileSync('src/data/articles.json', 'utf8')).filter(a => a.status === 'published' || a.status === undefined);
  const r = checkTaxonomy(articles, tree);
  for (const b of r.bands) console.log(`${b.ok ? 'ok  ' : 'FAIL'} ${b.slug} ${b.count}${b.ruling ? ' (ruling: ' + b.ruling + ')' : ''}`);
  if (r.unresolved.length) console.log(`FAIL unresolved paths (${r.unresolved.length}): ${r.unresolved.slice(0, 10).join(', ')}${r.unresolved.length > 10 ? ' ...' : ''}`);
  process.exit(r.ok ? 0 : 1);
}
```

```js
#!/usr/bin/env node
// scripts/taxonomy/agreement.mjs: G3. Jev's decisions vs Gianna's labels on the sample; domain >= 0.85, topic >= 0.75, calibrated.
import { readFileSync } from 'node:fs';

const seg = (p, n) => (p ? p.split('/').slice(0, n).join('/') : null);

export function agreement(decisions, labels) {
  const byId = new Map(decisions.map(d => [d.id, d]));
  let dAgree = 0, tAgree = 0, tN = 0; const disagreements = []; const confA = [], confD = [];
  for (const l of labels) {
    const d = byId.get(l.id); const jev = d?.paths?.[0] ?? null;
    const domOk = seg(jev, 1) === seg(l.path, 1); if (domOk) dAgree++;
    if (l.path.split('/').length >= 2) { tN++; if (seg(jev, 2) === seg(l.path, 2)) tAgree++; }
    const conf = d?.confidence?.domain ?? 0;
    (domOk ? confA : confD).push(conf);
    if (!domOk || (l.path.split('/').length >= 2 && seg(jev, 2) !== seg(l.path, 2))) disagreements.push({ id: l.id, jev, gianna: l.path, conf, brian: '' });
  }
  const mean = xs => xs.length ? xs.reduce((a, b) => a + b, 0) / xs.length : 0;
  const meanConfAgree = mean(confA), meanConfDisagree = mean(confD);
  return { n: labels.length, domain: { agree: dAgree, rate: dAgree / labels.length }, topic: { agree: tAgree, n: tN, rate: tN ? tAgree / tN : null }, calibrated: meanConfAgree > meanConfDisagree, meanConfAgree, meanConfDisagree, disagreements };
}

export function verdict(r) { return r.domain.rate >= 0.85 && (r.topic.rate === null || r.topic.rate >= 0.75) && r.calibrated; }

if (process.argv[1] && import.meta.url.endsWith(process.argv[1].split('/').pop())) {
  const lines = f => readFileSync(f, 'utf8').split('\n').filter(Boolean).map(l => JSON.parse(l));
  const decisions = lines('.run/taxonomy/decisions.jsonl'); const labels = lines('.run/taxonomy/sample-labels.jsonl');
  const r = agreement(decisions, labels);
  console.log(JSON.stringify({ n: r.n, domain: r.domain, topic: r.topic, calibrated: r.calibrated, meanConfAgree: +r.meanConfAgree.toFixed(3), meanConfDisagree: +r.meanConfDisagree.toFixed(3), G3: verdict(r) ? 'MET' : 'NOT MET' }, null, 2));
  require('node:fs').writeFileSync('.run/taxonomy/disagreements.json', JSON.stringify(r.disagreements, null, 2));
  process.exit(verdict(r) ? 0 : 1);
}
```

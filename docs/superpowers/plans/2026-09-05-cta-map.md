# CTA Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every money and lead-capture element on the site a closed-vocabulary `data-cta` id, a build-time lint gate that fails the build when one is missing or malformed, a generated inventory (`docs/cta-map.json`/`.md`), and a `cta_click` beacon that actually carries that id into GA4 and the D1 conversion ledger.

**Architecture:** A closed vocabulary (`src/data/cta-vocabulary.json`) is validated by a small loader (`scripts/lib/cta-vocabulary.mjs`) shared between the lint gate and its tests. `scripts/check-cta-map.mjs` runs in two modes: a fast source-mode pass over `.astro` files (wired pre-`astro build` in the `build` npm script and as its own step in `merge.yml`, which never builds) and a dist-mode pass over `dist/**/*.html` (wired post-`astro build` in `deploy.yml`, the only workflow where `dist/` exists) that catches composition-level duplicates and emits the committed `docs/cta-map.json`/`.md`. `track-auto.ts` is extended to read `[data-cta]` (and, for one release, the legacy `[data-track-cta]` through a rename table so old and new never double-fire) and sends `cta_click` with `id`/`page`/`cta_zone`/`cta_intent`. `_ga4.js` adds `cta_click` to `LEDGER_EVENTS` with a new `deriveLedgerType` branch, deliberately keeping it out of `LEDGER_USER_EVENTS`. `functions/api/funnel.js` in `rrm-backoffice` is NOT touched.

**Tech Stack:** Astro components (`.astro`), a client TypeScript module bundled by Astro (`track-auto.ts`), CF Pages Functions (ESM JS), D1 (SQLite), node:test, a hand-rolled attribute-regex HTML scanner (matching the existing `check-canonical-lockdown.mjs`/`check-render-gate-ids.mjs` style, no HTML parser dependency).

**Spec:** `docs/superpowers/specs/2026-09-05-attribution-cta-map-ltv-design.md` (§4 Workstream 2: CTA map, in full; the §5.1 sentence that `FUNNEL_EVENTS`/`TYPED_EVENTS` in the backoffice are NOT extended; §7 step 3's proof checklist)

**Prior work:** Workstream 1 (first-touch attribution, migration 039, `rrm_ft` cookie) shipped today on `main`, commits `cabb444b..5fda6550`. This plan does not depend on it and does not touch `ft_*` columns. Workstream 3 (backoffice CTA table surfaces) is explicitly out of scope for this plan.

## Global Constraints

- `$SCRATCH` in every command below is the session scratchpad directory, never `/tmp`.
- CTA id shape: `<page>.<zone>.<intent>`, lowercase, hyphenated tokens, regex `^[a-z0-9-]+\.[a-z0-9-]+\.[a-z0-9-]+$`, maximum 64 chars (matches `LEDGER_SHORT_CAP` in `functions/api/_ga4.js`, not the larger figure the regex alone would allow). `page` is a route FAMILY, never a slug (the ledger's own `page_location`/pathname already carries the slug). The vocabulary (`src/data/cta-vocabulary.json`) is the only place a new page/zone/intent token is added.
- `REQUIRED_PARAMS.get('cta_click')` in `functions/api/_track-events.js` STAYS `['id', 'page']`. `id` IS the full `page.zone.intent` cta id; `page` IS `location.pathname`. There is no separate `cta`/`cta_page` param name. `cta_zone` and `cta_intent` are new OPTIONAL params carried on the same beacon; they need no allowlist entry because they are not in `RESERVED_PARAMS` and do not match `PII_REGEX`, so the existing generic sanitize-and-pass-through path already accepts them at the 100-char default string cap.
- The legacy `data-track-cta` attribute and the `track-auto.ts` listener that reads it are NOT deleted in this plan. Both listeners run for one release, keyed through an explicit rename table so an element carrying both attributes (during the transition) fires exactly one `cta_click`, never two. Removing the legacy attribute and listener is a follow-up task, listed in Task 5 but not executed here.
- Guarded files touched by this plan: `functions/api/_track-events.js`, `functions/api/track.js`, `functions/api/_ga4.js`. `src/layouts/BaseLayout.astro` is NOT touched (track-auto.ts is already imported there from a prior workstream). Every task that edits a guarded file ends with `npm run guard:update` in the same commit.
- `functions/api/funnel.js` in the separate `rrm-backoffice` repository is NOT touched by any task in this plan. `FUNNEL_EVENTS` and `TYPED_EVENTS` there keep their current five/four-event shape. `cta_click` must never appear as a sixth funnel stage.
- Migration 036 (`migrations/036-conversion-ledger.sql`) is NOT schema-altered (the `type` TEXT column already exists and already accepts any string up to the application-enforced 64-char cap). Only its header's TYPE-derivation comment block is amended, in the same commit that adds the `cta_click` branch to `deriveLedgerType`.
- `value_cents` for a `cta_click` ledger row is always NULL (no call site sends a `value` param on this beacon).
- Commit messages: always written to a scratch file first and passed with `git commit -F <file>`, never `git commit -m` with long text. Every commit message ends with the trailer line `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- No em dashes in any prose or comment added by this plan. American English throughout.
- **Lint gate wiring decision (resolves the pre-build-vs-post-build question):** `scripts/check-cta-map.mjs` runs in TWO invocations, not one, because `dist/` does not exist before `astro build` and `merge.yml` never runs `astro build` at all (confirmed: no `npm run build`/`astro build` step in `.github/workflows/merge.yml`). A single post-build-only invocation would therefore be silently skipped in `merge.yml`, the one place `merge.yml` explicitly needs it to run. So:
  - `node scripts/check-cta-map.mjs --mode=source` runs on `.astro` files only (rules 1, 2, 2b, and the per-component uniqueness sub-check). Wired into the `build` npm script BEFORE `astro build` (mirrors `check-render-gate-ids.mjs`'s position), and as its own step in `merge.yml` (which has no `dist/` to check).
  - `node scripts/check-cta-map.mjs --mode=dist` runs on `dist/**/*.html` only (rule 3's per-rendered-page duplicate check, `docs/cta-map.json`/`.md` generation, and the zero-CTA scan). Wired into `deploy.yml` as its own step immediately after the existing "Build site" step (the only workflow where `dist/` exists).
  - Both modes share the same rule implementations from `scripts/lib/cta-map-rules.mjs` so a rule is never defined twice.
- **Rule 2 attribute-presence reading (documented interpretation, not the literal wording):** §4.3 rule 2 lists `data-tier`, `data-checkout`, `data-enroll` as attributes whose PRESENCE (not URL-shaped value) signals a money/lead element -- `data-tier="member"` on `donate/index.astro`'s tier buttons is not itself a URL. The gate implements presence-based triggering for these three names. The codebase's actual course-enroll buttons (`src/pages/courses/[slug].astro`) carry `data-course-id`, not `data-enroll` -- the gate's attribute list is extended to include `data-course-id` so enroll buttons are covered; documented in code and flagged again at the end of this plan.
- **Rule 2b literal-set extension (documented interpretation):** §4.3 rule 2b names exactly three literals (`/api/create-checkout`, `/api/billing/portal`, `mailto:`) that must appear in an inline `<script>` alongside a matching `id`. Documented in code and flagged again at the end of this plan.
- `/` and `javascript:` targets stay explicitly out of scope for rules 2 and 2b (no money or PII crosses either).

```js
// scripts/lib/cta-vocabulary.mjs
// Single source of truth for CTA id validation: the id shape, the 64-char
// cap (LEDGER_SHORT_CAP in functions/api/_ga4.js), and membership in the
// closed page/zone/intent vocabulary (src/data/cta-vocabulary.json).
// Shared by scripts/check-cta-map.mjs (build-time gate) and this module's
// own test. Never hand-list the vocabulary anywhere else.
//
// Spec: docs/superpowers/specs/2026-09-05-attribution-cta-map-ltv-design.md §4.1

import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, resolve } from 'node:path';

const __dirname = dirname(fileURLToPath(import.meta.url));
const VOCAB_PATH = resolve(__dirname, '../../src/data/cta-vocabulary.json');

// data-cta="<page>.<zone>.<intent>", lowercase, hyphenated tokens.
export const CTA_ID_REGEX = /^[a-z0-9-]+\.[a-z0-9-]+\.[a-z0-9-]+$/;

// Matches LEDGER_SHORT_CAP in functions/api/_ga4.js -- the ledger's `type`
// column binds a cta_click id verbatim, so a composed id longer than this
// would be silently truncated at the ledger boundary. NOT derivable from
// CTA_ID_REGEX alone (a naive reading of the regex allows well over 100
// chars); this is a separate, explicit cap.
export const CTA_ID_MAX_LENGTH = 64;

let cached = null;

/** Loads and validates src/data/cta-vocabulary.json. Cached after first call. */
export function loadCtaVocabulary() {
  if (cached) return cached;
  const raw = readFileSync(VOCAB_PATH, 'utf8');
  const parsed = JSON.parse(raw);
  for (const key of ['pages', 'zones', 'intents']) {
    if (!Array.isArray(parsed[key]) || parsed[key].length === 0) {
      throw new Error(`cta-vocabulary.json: "${key}" must be a non-empty array`);
    }
    for (const token of parsed[key]) {
      if (typeof token !== 'string' || !/^[a-z0-9-]+$/.test(token)) {
        throw new Error(`cta-vocabulary.json: "${key}" contains an invalid token "${token}"`);
      }
    }
  }
  cached = {
    pages: new Set(parsed.pages),
    zones: new Set(parsed.zones),
    intents: new Set(parsed.intents),
  };
  return cached;
}

/**
 * Validates one candidate CTA id against the regex, the length cap, and
 * vocabulary membership. Returns a reason string (not just a boolean) so
 * the lint gate can name the exact defect at the exact file/line.
 */
export function validateCtaId(id) {
  if (typeof id !== 'string' || id.length === 0) {
    return { ok: false, reason: 'data-cta value is empty or not a string' };
  }
  if (id.length > CTA_ID_MAX_LENGTH) {
    return { ok: false, reason: `data-cta "${id}" exceeds the ${CTA_ID_MAX_LENGTH}-char cap (LEDGER_SHORT_CAP)` };
  }
  if (!CTA_ID_REGEX.test(id)) {
    return { ok: false, reason: `data-cta "${id}" does not match ^[a-z0-9-]+\\.[a-z0-9-]+\\.[a-z0-9-]+$` };
  }
  const [page, zone, intent] = id.split('.');
  const vocab = loadCtaVocabulary();
  if (!vocab.pages.has(page)) return { ok: false, reason: `data-cta "${id}": page token "${page}" is not in cta-vocabulary.json pages` };
  if (!vocab.zones.has(zone)) return { ok: false, reason: `data-cta "${id}": zone token "${zone}" is not in cta-vocabulary.json zones` };
  if (!vocab.intents.has(intent)) return { ok: false, reason: `data-cta "${id}": intent token "${intent}" is not in cta-vocabulary.json intents` };
  return { ok: true };
}

/** Boolean convenience wrapper for call sites that don't need the reason. */
export function isValidCtaId(id) {
  return validateCtaId(id).ok;
}
```

/**
 * Unit tests for scripts/lib/cta-vocabulary.mjs.
 * Run with: node --test test/cta-vocabulary.test.mjs
 */
import { describe, it } from 'node:test';
import assert from 'node:assert/strict';
import { CTA_ID_REGEX, CTA_ID_MAX_LENGTH, validateCtaId, isValidCtaId, loadCtaVocabulary } from '../scripts/lib/cta-vocabulary.mjs';

describe('cta-vocabulary -- CTA_ID_REGEX', () => {
  it('accepts a well-formed three-token id', () => {
    assert.match('donate.tiers.join-stuc-member', CTA_ID_REGEX);
  });
  it('rejects fewer than three tokens', () => {
    assert.doesNotMatch('donate.tiers', CTA_ID_REGEX);
  });
  it('rejects uppercase', () => {
    assert.doesNotMatch('Donate.tiers.donate', CTA_ID_REGEX);
  });
  it('rejects underscores', () => {
    assert.doesNotMatch('donate.tiers.join_stuc_member', CTA_ID_REGEX);
  });
});

describe('cta-vocabulary -- validateCtaId', () => {
  it('passes a real vocabulary id', () => {
    assert.deepEqual(validateCtaId('donate.tiers.join-stuc-member'), { ok: true });
  });
  it('fails on an unknown page token', () => {
    const r = validateCtaId('checkout.tiers.donate');
    assert.equal(r.ok, false);
    assert.match(r.reason, /page token "checkout"/);
  });
  it('fails on an unknown zone token', () => {
    const r = validateCtaId('donate.banner.donate');
    assert.equal(r.ok, false);
    assert.match(r.reason, /zone token "banner"/);
  });
  it('fails on an unknown intent token', () => {
    const r = validateCtaId('donate.tiers.subscribe-now');
    assert.equal(r.ok, false);
    assert.match(r.reason, /intent token "subscribe-now"/);
  });
  it('fails over the 64-char cap even when every token is otherwise valid', () => {
    const longButValidShape = `home.hero.${'learn-'.repeat(12)}home`;
    assert.ok(longButValidShape.length > CTA_ID_MAX_LENGTH);
    const r = validateCtaId(longButValidShape);
    assert.equal(r.ok, false);
    assert.match(r.reason, /exceeds the 64-char cap/);
  });
  it('isValidCtaId is a boolean-only wrapper', () => {
    assert.equal(isValidCtaId('donate.tiers.join-stuc-member'), true);
    assert.equal(isValidCtaId('donate.tiers.subscribe-now'), false);
  });
});

describe('cta-vocabulary -- loadCtaVocabulary', () => {
  it('loads three non-empty Sets', () => {
    const vocab = loadCtaVocabulary();
    assert.ok(vocab.pages.size > 0);
    assert.ok(vocab.zones.size > 0);
    assert.ok(vocab.intents.size > 0);
    assert.ok(vocab.zones.has('footer-col-1'));
    assert.ok(vocab.zones.has('footer-col-4'));
    assert.ok(vocab.pages.has('nav-mobile'));
    assert.ok(vocab.intents.has('retry'));
  });
});

// scripts/lib/cta-map-rules.mjs
// Shared rule implementations for scripts/check-cta-map.mjs. Split out so
// source-mode and dist-mode share one definition of every rule instead of
// two drifting copies.
//
// Spec: docs/superpowers/specs/2026-09-05-attribution-cta-map-ltv-design.md §4.3

import { validateCtaId } from './cta-vocabulary.mjs';

// Rule 2: an <a>/<button>/<form> whose href/action value matches one of
// these path prefixes MUST carry data-cta. mailto: is included here too --
// a STATIC mailto href (not a JS-built one, which rule 2b covers) still
// needs a data-cta.
export const TARGET_PATH_PATTERNS = [
  /^\/donate\/?/,
  /^\/api\/create-checkout/,
  /^\/api\/billing\/portal/,
  /^\/save-the-uterus-club\/?/,
  /^\/api\/newsletter\/subscribe/,
  /^\/api\/endo-quiz\//,
  /^\/api\/survey\//,
  /^\/courses\/.*\/enroll/,
  // Extension beyond the literal spec text: the real enroll endpoint the
  // codebase calls is /api/courses/enroll (fetch from an inline script),
  // not a /courses/<slug>/enroll href. See the plan's Global Constraints.
  /^\/api\/courses\/enroll/,
  /^\/signup\/?/,
  /^\/login\/?/,
  /^\/account\/?/,
  /^\/providers\/?/,
  /^mailto:/,
];

// Rule 2's attribute-presence trigger: an element carrying ANY of these
// attributes (regardless of value) is presumed money/lead-flow, mirroring
// donate/index.astro's `data-tier="member"` (the value is a tier name, not
// a URL). data-course-id is an extension: the spec names `data-enroll`,
// but src/pages/courses/[slug].astro's real enroll buttons carry
// data-course-id. See the plan's Global Constraints.
export const TRIGGER_ATTRS = ['data-tier', 'data-checkout', 'data-enroll', 'data-course-id'];

// Rule 2b's literal set. Extension beyond the spec's three named literals:
// see the plan's Global Constraints for why the newsletter/quiz/survey
// lead forms and /api/courses/enroll require this.
export const RULE_2B_LITERALS = [
  '/api/create-checkout',
  '/api/billing/portal',
  'mailto:',
  '/api/newsletter/subscribe',
  '/api/endo-quiz/',
  '/api/survey/',
  '/api/courses/enroll',

// Strips Astro frontmatter fences so attribute scanning never matches JS
// template-literal noise in the component script block.
export function stripFrontmatter(source) {
  if (!source.startsWith('---')) return source;
  const end = source.indexOf('\n---', 3);
  return end === -1 ? source : source.slice(end + 4);
}

/** Extracts every <script>...</script> body (inline or define:vars) from a file. */
export function extractInlineScripts(source) {
  const scripts = [];
  const re = /<script[^>]*>([\s\S]*?)<\/script>/g;
  let m;
  while ((m = re.exec(source)) !== null) scripts.push(m[1]);
  return scripts;
}

/**
 * Finds every rule-2/rule-2b candidate element in one file's markup and
 * returns violations (elements missing a valid data-cta).
 *
 * `filePath` is used only for error messages. `source` is the FULL file
 * content (frontmatter included) -- rule 2b needs both the markup and the
 * script text from the SAME file per spec ("in the same file").
 */
export function findMoneyElementViolations(filePath, source, requiredIdSet) {
  const violations = [];
  const markup = stripFrontmatter(source);
  const scripts = extractInlineScripts(markup).join('\n');

  // --- Rule 2: href/action value match OR trigger-attribute presence ---
  const tagRe = /<(a|button|form)\b([^>]*)>/g;
  let m;
  while ((m = tagRe.exec(markup)) !== null) {
    const [full, tag, attrsRaw] = m;
    const hrefMatch = attrsRaw.match(/\s(?:href|action)\s*=\s*["']([^"']*)["']/);
    const hasTriggerAttr = TRIGGER_ATTRS.some((a) => new RegExp(`\\s${a}(\\s*=|[\\s>])`).test(attrsRaw));
    const targetValue = hrefMatch ? hrefMatch[1] : '';
    const matchesTarget = targetValue && TARGET_PATH_PATTERNS.some((p) => p.test(targetValue));
    if (!matchesTarget && !hasTriggerAttr) continue;
    // '/' and 'javascript:' are explicitly out of scope.
    if (targetValue === '/' || targetValue.startsWith('javascript:')) continue;

    const dataCtaMatch = attrsRaw.match(/\sdata-cta\s*=\s*\{?["']?([\w.-]*)/);
    const idOfElement = (attrsRaw.match(/\sid\s*=\s*["']([^"']*)["']/) || [])[1] || '(no id)';
    if (!dataCtaMatch) {
      violations.push({ filePath, tag, id: idOfElement, reason: `<${tag}> targets a money/lead path but has no data-cta attribute` });
      continue;
    }
    const validity = validateCtaId(dataCtaMatch[1]);
    if (!validity.ok) violations.push({ filePath, tag, id: idOfElement, reason: validity.reason });
  }

  // --- Rule 2b: id-based JS-driven buttons the href scan cannot see ---
  const hasCheckoutLiteral = RULE_2B_LITERALS.some((lit) => scripts.includes(lit));
  if (hasCheckoutLiteral) {
    const idTagRe = /<(a|button|form)\b([^>]*\sid\s*=\s*["']([^"']+)["'][^>]*)>/g;
    let idm;
    while ((idm = idTagRe.exec(markup)) !== null) {
      const [, tag, attrsRaw, elementId] = idm;
      const literalInScript = scripts.includes(`'${elementId}'`) || scripts.includes(`"${elementId}"`) || scripts.includes(`#${elementId}`);
      if (!literalInScript) continue;
      const isAllowlisted = requiredIdSet.has(elementId);
      const dataCtaMatch = attrsRaw.match(/\sdata-cta\s*=\s*\{?["']?([\w.-]*)/);
      if (!dataCtaMatch) {
        violations.push({ filePath, tag, id: elementId, reason: `#${elementId} is referenced from an inline script alongside a money/lead endpoint but has no data-cta attribute${isAllowlisted ? ' (and is in cta-required-ids.json)' : ''}` });
        continue;
      }
      const validity = validateCtaId(dataCtaMatch[1]);
      if (!validity.ok) violations.push({ filePath, tag, id: elementId, reason: validity.reason });
    }
  }

  return violations;
}

/** Extracts every data-cta="..." value from one rendered HTML string, in order. */
export function extractCtaOccurrences(html) {
  const out = [];
  const re = /<([a-z][\w-]*)\b[^>]*\sdata-cta\s*=\s*["']([^"']+)["'][^>]*>([\s\S]*?)<\/\1>/gi;
  let m;
  while ((m = re.exec(html)) !== null) {
    const label = m[3].replace(/<[^>]+>/g, ' ').replace(/\s+/g, ' ').trim().slice(0, 80);
    out.push({ tag: m[1], ctaId: m[2], label });
  }
  return out;
}

/** True when a data-cta id's page token is site-wide chrome (exempt from per-page dedup). */
export function isChromeCta(ctaId) {
  return ctaId.startsWith('header.') || ctaId.startsWith('footer.') || ctaId.startsWith('nav-mobile.');
}

#!/usr/bin/env node
// scripts/check-cta-map.mjs
// Lint gate + generated inventory for the closed-vocabulary data-cta
// attribute. Two modes because dist/ does not exist before `astro build`
// and merge.yml never builds -- see the plan's Global Constraints for why.
//
//   --mode=source : scans .astro under src/. Rules 1, 2, 2b, per-component
//                    uniqueness. Fast, no build required.
//   --mode=dist   : scans dist/**/*.html. Rule 3 (per-rendered-page
//                    duplicates), zero-CTA scan, emits docs/cta-map.json/.md.
//
// Run via `npm run build` (source mode, pre-astro-build) and as its own CI
// step in deploy.yml (dist mode, post-astro-build) and merge.yml (source
// mode only -- merge.yml never builds).
//
// Spec: docs/superpowers/specs/2026-09-05-attribution-cta-map-ltv-design.md §4.3

import { readFileSync, writeFileSync, readdirSync, statSync, existsSync } from 'node:fs';
import { join, relative } from 'node:path';
import { fileURLToPath } from 'node:url';
import { dirname, resolve } from 'node:path';
import { validateCtaId, isValidCtaId } from './lib/cta-vocabulary.mjs';
import { findMoneyElementViolations, extractCtaOccurrences, isChromeCta } from './lib/cta-map-rules.mjs';

const __dirname = dirname(fileURLToPath(import.meta.url));
const REPO_ROOT = resolve(__dirname, '..');
const REQUIRED_IDS_PATH = resolve(REPO_ROOT, 'src/data/cta-required-ids.json');

function walk(dir, extFilter) {
  const out = [];
  if (!existsSync(dir)) return out;
  for (const entry of readdirSync(dir)) {
    const full = join(dir, entry);
    const st = statSync(full);
    if (st.isDirectory()) out.push(...walk(full, extFilter));
    else if (extFilter(entry)) out.push(full);
  }
  return out;
}

function loadRequiredIdSet() {
  const raw = JSON.parse(readFileSync(REQUIRED_IDS_PATH, 'utf8'));
  return new Set(raw.ids || []);
}

// ---------------------------------------------------------------- source ---

function runSourceMode() {
  const failures = [];
  const requiredIdSet = loadRequiredIdSet();
  const files = walk(resolve(REPO_ROOT, 'src'), (f) => f.endsWith('.astro'));
  if (files.length === 0) {
    console.error('FAIL: zero .astro files found under src/ -- the scan itself is broken');
    process.exit(1);
  }

  // Rule 1 + 2 + 2b
  for (const filePath of files) {
    const source = readFileSync(filePath, 'utf8');
    const violations = findMoneyElementViolations(relative(REPO_ROOT, filePath), source, requiredIdSet);
    failures.push(...violations);
  }

  // Per-component uniqueness (the site-wide-chrome half of rule 3): a
  // single component file (Header/Footer/etc.) must never define the same
  // data-cta value twice within itself, even though its rendered dedup
  // check is exempted per-page.
  for (const filePath of files) {
    const source = readFileSync(filePath, 'utf8');
    const occurrences = extractCtaOccurrences(source);
    const seen = new Map();
    for (const { ctaId } of occurrences) {
      seen.set(ctaId, (seen.get(ctaId) || 0) + 1);
      if (seen.get(ctaId) === 2) {
        failures.push({ filePath: relative(REPO_ROOT, filePath), tag: '', id: ctaId, reason: `data-cta "${ctaId}" is defined more than once within this single component file` });
      }
    }
  }

  if (failures.length > 0) {
    console.error(`FAIL (source mode): ${failures.length} data-cta violation(s):`);
    for (const f of failures) console.error(`  ${f.filePath} <${f.tag}> id="${f.id}": ${f.reason}`);
    process.exit(1);
  }
  console.log(`PASS (source mode): ${files.length} .astro files scanned, zero violations`);
}

// ------------------------------------------------------------------ dist ---

// Best-effort dist path -> likely source file, for docs/cta-map.json's
// "source" column. This is a heuristic, not a real source map -- the
// build produces no such map today. Unmapped pages fall back to 'unknown'.
function guessSourceFile(pagePath) {
  if (pagePath === '/' || pagePath === '/index.html') return 'src/pages/index.astro';
  const trimmed = pagePath.replace(/^\//, '').replace(/\/?(index\.html)?$/, '');
  if (!trimmed) return 'src/pages/index.astro';
  const candidates = [
    `src/pages/${trimmed}/index.astro`,
    `src/pages/${trimmed}.astro`,
  ];
  for (const c of candidates) {
    if (existsSync(resolve(REPO_ROOT, c))) return c;
  }
  return 'unknown';
}

function runDistMode() {
  const distDir = resolve(REPO_ROOT, 'dist');
  if (!existsSync(distDir)) {
    console.error('FAIL: dist/ does not exist -- dist mode must run AFTER `astro build`');
    process.exit(1);
  }
  const files = walk(distDir, (f) => f.endsWith('.html'));
  const failures = [];
  const rows = [];

  for (const filePath of files) {
    const html = readFileSync(filePath, 'utf8');
    const pagePath = '/' + relative(distDir, filePath).replace(/index\.html$/, '').replace(/\.html$/, '');
    const occurrences = extractCtaOccurrences(html);
    const seenOnPage = new Map();

    for (const { tag, ctaId, label } of occurrences) {
      const validity = validateCtaId(ctaId);
      if (!validity.ok) {
        failures.push(`${pagePath}: ${validity.reason}`);
        continue;
      }
      if (!isChromeCta(ctaId)) {
        seenOnPage.set(ctaId, (seenOnPage.get(ctaId) || 0) + 1);
        if (seenOnPage.get(ctaId) === 2) {
          failures.push(`${pagePath}: duplicate data-cta "${ctaId}" on one rendered page`);
        }
      }
      rows.push({
        page: pagePath,
        ctaId,
        label,
        elementType: tag,
        source: guessSourceFile(pagePath),
      });
    }
  }

  if (rows.length === 0) {
    console.error('FAIL: zero data-cta elements found across the entire built site -- the scan itself is broken');
    process.exit(1);
  }
  if (failures.length > 0) {
    console.error(`FAIL (dist mode): ${failures.length} violation(s):`);
    for (const f of failures) console.error(`  ${f}`);
    process.exit(1);
  }

  writeFileSync(resolve(REPO_ROOT, 'docs/cta-map.json'), JSON.stringify(rows, null, 2) + '\n');
  const byPage = new Map();
  for (const r of rows) {
    if (!byPage.has(r.page)) byPage.set(r.page, []);
    byPage.get(r.page).push(r);
  }
  let md = '# CTA Map\n\nGenerated by `scripts/check-cta-map.mjs --mode=dist`. Never hand-edited.\n\n';
  for (const [page, pageRows] of byPage) {
    md += `## ${page}\n\n| CTA id | Element | Label | Source |\n|---|---|---|---|\n`;
    for (const r of pageRows) md += `| \`${r.ctaId}\` | ${r.elementType} | ${r.label || '(no text)'} | \`${r.source}\` |\n`;
    md += '\n';
  }
  writeFileSync(resolve(REPO_ROOT, 'docs/cta-map.md'), md);
  console.log(`PASS (dist mode): ${files.length} pages, ${rows.length} data-cta elements, docs/cta-map.json + .md written`);
}

function main() {
  const mode = (process.argv.find((a) => a.startsWith('--mode=')) || '--mode=source').split('=')[1];
  if (mode === 'source') runSourceMode();
  else if (mode === 'dist') runDistMode();
  else { console.error(`unknown --mode "${mode}", expected source|dist`); process.exit(1); }
}

main();

```ts
    // ── 2. CTA clicks ───────────────────────────────────────────────────
    // Bubble-phase: by the time it reaches document the value is final.
    //
    // Reads [data-cta] (the closed-vocabulary "<page>.<zone>.<intent>" id,
    // see docs/superpowers/specs/2026-09-05-attribution-cta-map-ltv-design.md
    // §4) FIRST, and falls back to the legacy [data-track-cta] attribute for
    // one release through LEGACY_CTA_RENAME_MAP -- an element carrying BOTH
    // attributes fires exactly once, matching data-cta and never re-firing
    // on the legacy path. LEGACY_CTA_RENAME_MAP is deleted, along with this
    // fallback branch and every remaining data-track-cta attribute in the
    // codebase, in the release after this one ships.
    document.addEventListener(
      'click',
      (e: MouseEvent) => {
        const target = e.target as Element | null;
        if (!target) return;
        const cta = target.closest?.('[data-cta], [data-track-cta]') as HTMLElement | null;
        if (!cta) return;

        const newId = cta.getAttribute('data-cta');
        const legacyId = cta.getAttribute('data-track-cta');
        // newId wins when both are present -- this is what makes an element
        // carrying both attributes during the transition fire exactly once.
        const id = newId || (legacyId ? LEGACY_CTA_RENAME_MAP[legacyId] || legacyId : null);
        if (!id) return;

        const [page, zone, intent] = id.includes('.') ? id.split('.') : [];
        const position = cta.getAttribute('data-track-position') || undefined;
        const value = cta.getAttribute('data-track-value');
        const numericValue = value != null && value !== '' ? Number(value) : NaN;

        track('cta_click', {
          id,
          page: location.pathname,
          ...(zone ? { cta_zone: zone } : {}),
          ...(intent ? { cta_intent: intent } : {}),
          ...(position ? { position } : {}),
          ...(Number.isFinite(numericValue) ? { value: numericValue } : {}),
        });
      },
      false,
    );
```

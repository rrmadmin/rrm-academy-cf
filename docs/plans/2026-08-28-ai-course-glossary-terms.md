# AI Zero to Hero: Course Glossary Term List

Date: 2026-08-28. Status: DRAFT for Brian review. Parent plan: `2026-08-28-ai-zero-to-hero-course-track.md`.

The 40-term SSOT for the course track. Doubles as the flashcard deck. Definitions get written at lesson-draft stage; this list fixes WHICH terms, their grouping, and where each is introduced. Structure rule: no term appears in a lesson before its module introduces it.

NOT the site glossary at /glossary/ (RRM medical terms). This is a separate course asset.

## Group A: The machinery (Course 1, modules 1-3)

1. Artificial intelligence (AI)
2. Machine learning
3. Large language model (LLM)
4. Generative AI
5. Model
6. Parameters / weights
7. Training data
8. Pretraining
9. Fine-tuning
10. RLHF (human feedback training)
11. Knowledge cutoff
12. Inference
13. GPU / compute

## Group B: The conversation (Course 1, module 4)

14. Prompt
15. Token
16. Context
17. Context window
18. System prompt
19. Temperature / randomness
20. Output / completion

## Group C: Failure modes and judgment (Course 1, modules 5-6)

21. Hallucination
22. Fabricated citation
23. Bias (training-data bias)
24. Grounding
25. Verification

## Group D: Capabilities and architecture around the model (Course 1, modules 6-7)

26. Reasoning model (thinking model)
27. Retrieval / RAG (the model looking things up vs knowing)
28. Web search (in-chat)
29. Multimodal (vision, voice)
30. Agent
31. Skill / tool (what an agent can do)
32. Ambient scribe
33. Model tier / model family (e.g. fast vs frontier)
34. Open vs closed model

## Group E: Privacy and deployment (Course 1, module 8)

35. PHI (in the AI context: why it never enters consumer tools)
36. De-identification
37. BAA (what it changes and what it doesn't)
38. Training on your data (opt-outs, enterprise vs consumer)

## Group F: Personalization (introduced Course 3, module 3)

39. Custom instructions
40. Memory (persistent) vs context window (per-conversation)
41. Project / custom GPT (a saved workspace: instructions + files + chats)

## Flashcard format (per term)

- Front: term
- Back: plain-language definition (1-2 sentences) + one clinical-relevance line ("why you care")
- Metadata: group, introducing module id

## Authoring notes

- Definitions written WITH course 1 lesson drafts so wording matches the lesson verbatim (one phrasing, everywhere).
- 41 terms lands in the 30-40 target range (one over; trim candidate: GPU/compute could fold into inference).
- Courses 2-3 introduce no new machinery terms; they deepen usage of these.
